# AKKI OS — INTENT INTEGRITY & INTERPRETATION LEARNING SPECIFICATION v1.0
### CIF × Targeta at every user-intent boundary · 2026-08-01 · supersedes the v1.0 DRAFT

## §1 · RULING AND MECHANISM

Owner ruling: anywhere a user states intent or assigns work to an LLM,
counter-silent-objective machinery activates — silent skew at intent capture
multiplies through mining spend.

The mechanism is a two-engine loop. **CIF caps the cost of any single skew**:
interpretive assumptions are surfaced and confirmed before spend. **Targeta
reduces the frequency of skew**: confirmed corrections train the proposer, so
protection overhead falls over cycles instead of standing as a permanent tax.
The wall: Targeta trains the PROPOSER only, never the confirmer — better
readings offered, never self-adopted. Detection never decides; learning never
widens reach; the human seat confirms, permanently (CIF §9).

Doctrine carried: no sibling services; gates bind spend/quality/claims, never
existence; verdict evidence never curated (D-7); contract movement only
through seal events.

## §3 · CIF COMPONENTS (detection, pre-spend)

**3.1 Interpretation manifests.** Every intent translation records its
load-bearing interpretive assumptions, classed user-said (turn-cited) /
recalled (source-cited) / inferred (agent-supplied), elicited by the probe:
*what, if read differently, changes what gets mined?* Extends the built
CommittedValue XOR pattern from values to readings.

**3.2 Selection manifests.** Where the LLM picked among readings or
configurations, the record carries why the pick ranked first and what was
passed over. Extends the turn ledger with candidate rankings.

**3.3 Rejected-interpretation archive.** Passed-over readings land with
named conditions, rent-dated (A2.3); append-only ledger rows; standing
query surfaces evaluated-but-unarchived readings.

**3.4 Adversarial elicitation at the sample→commission seam.** A second
instance satisfying the independence rule interrogates the manifest for
unstated skew (cheaper-reading bias, scope narrowing, class avoidance).
Findings render as flagged assumptions on the card; never blocks, never
decides. Catch-rate ≥ 60% DEFAULT by seeded audit; cost within O-I2.

**3.5 THE FREEZE RULE (enforcement point, B2).** A commission MUST NOT
freeze while a load-bearing interpretive assumption stands
unconfirmed-inferred. Extends built Guard-1 exactly: operator-mandatory
values already refuse agent-supplied; load-bearing readings now do the
same. Refusal is escalatable-shaped: the assumption is named; confirming
it on the card is the route. Load-bearing designation per door: builder
derives the per-door list from the objective schema at Stage A; Owner
confirms the lists (O-I3).

**3.6 Flip-cascade.** A corrected confirmed assumption re-qualifies
everything downstream resting on it on paper BEFORE further spend:
affected strata pause and re-plan; unaffected strata continue. Resume
without the sweep record fails its cells (M2 pattern).

## §4 · TARGETA COMPONENTS (learning, post-confirmation)

**4.1 Training objects.** Each confirmation event emits a training object
through the EXISTING admission handoff: {user words · proposed reading ·
confirmed reading · boundary id · outcome class}. One provenance chain
with the session ledger.

**4.2 Signal weighting (O-class protection).** A CORRECTION carries full
training weight; an unexamined CONFIRMATION carries minimal weight
(click-through is not ground truth). The loop feeds on disagreement, not
fatigue. Weighting values are O-class seam values.

**4.3 One shared interpretation-learner, walled.** Single learner across
boundaries (interpretation is one skill; corrections compound shared).
It proposes readings, rankings, and seeds; it holds no adoption path, no
freeze path, no widened reach.

**4.4 Deployment: E-class bumps with per-boundary gates.** An improved
proposer ships as a versioned engine bump carrying its evaluation
verdict. Evaluation runs per boundary against that boundary's FROZEN
HOLDOUT — historical correction records drawn from measured composition,
uncurated (D-7), never trained on. The bump deploys per boundary only
where its holdout passes; a boundary that fails keeps its prior version.
Failed versions stay visible; rollback is a first-class outcome.

## §5 · DEGRADATION PROTECTIONS (all four, with their rule class)

| Failure mode | Protection | Class |
|---|---|---|
| Self-training collapse | Training pairs anchor to the human side (4.1) + correction-over-confirmation weighting (4.2) | O |
| Ratchet without reverse | Frozen uncurated holdout per boundary per bump; per-boundary deployment gates; visible failed versions; first-class rollback (4.4) | O (holdout requirement) / E (bump mechanics) |
| Homogenization | Rejected-reading archive persists alternatives (3.3); proposal-diversity per boundary and per-stratum correction rates as MONITORED rules — measured, reported, never blocking | Monitored |
| Metric gaming | Paired metric only (§6): correction rate falling counts ONLY while seeded-audit catch-rate holds; owner-confirmed catches only, self-graded value inadmissible (CIF §13.1) | O |

Cascade brake: false-escalation counting (QA-f pattern) — a thrashing loop
tightens thresholds rather than running hotter.

Constitutional placement: every protection above whose loosening weakens
the guard is O-class — changed only via Change-a-Rule, DPO-visible, per
the Class-D asymmetry logic. Proposer behavior is E-class. No protection
lives as a code constant.

## §6 · SUCCESS CONDITIONS (measured, ungameable by construction)

- **Primary pair:** pre-spend catch-rate rising (share of assumption
  corrections at the card vs mid-run/at-delivery) AND per-boundary
  correction rate falling across cycles — VALID ONLY while seeded-audit
  catch-rate holds ≥ floor. Either number alone proves nothing.
- Manifest hit-rate at flips ≥ 70% DEFAULT (struck assumption was in the
  manifest).
- Freeze-refusal break-in gate: attempt a freeze with an unconfirmed
  load-bearing inferred reading; it must fail.
- Holdout-gate break-in: attempt deployment of a bump to a boundary whose
  holdout failed; it must fail.
- Diversity and per-stratum monitors reporting on the Govern record.
- Machinery overhead metered within O-I2; breach shrinks the machinery,
  never product work (QA-e discipline).

## §7 · SURFACE RENDERING (zero new screens)

Reflection card gains "Resting on": interpretive assumptions with class
chips, same grammar as set/open/assumed. The Commission card confirms
flagged readings exactly as it confirms values — "conversation shapes;
the card commits" now covers interpretations. Rejected readings are
session drill-down. Seeds render their assumptions as `assumed` on open.
LIGHT tier renders the interpretation line in the existing evidence strip
only above threshold. Monitors render in the Govern record.

  post-correction spend resumes.
- All O-class values enter the Estate Rules Record with live test packs
